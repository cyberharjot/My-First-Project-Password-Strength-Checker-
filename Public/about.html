About This Project

This Password Strength Checker was developed as part of a 45-day Cyber Security Training program at Future Finders, assigned by Sant Baba Bhag Singh University, Jalandhar.

In today’s digital world, weak passwords are among the easiest ways for hackers to gain unauthorized access. The main aim of this tool is to demonstrate how quickly a weak password can be cracked using brute force, raising awareness about digital security.

The tool checks password complexity in real-time and encourages users to create strong passwords using a mix of characters, numbers, and symbols.

Technologies used in this project include:

  • HTML & CSS for layout and styling
  • JavaScript for password strength logic
  • Node.js with JSON for user data

Special thanks to our trainer Mr. Shrijan Shukla at Future Finders and the faculty of SBBSU for their guidance and support during this project.
