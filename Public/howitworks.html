How It Works

The Password Strength Checker is a tool designed to help users understand how strong or weak their password is. It provides real-time feedback based on password complexity and length, encouraging better password creation habits.

🔍 Strength Evaluation Criteria

The tool checks for:

  • Length of the password (longer = stronger)
  • Use of lowercase letters (a-z)
  • Use of uppercase letters (A-Z)
  • Inclusion of numbers (0-9)
  • Use of special characters (e.g., !@#$%^&*)
  • Avoiding repeated characters or common patterns

🛡️ Security Awareness

This tool also includes a brute force simulation feature. It shows how quickly a weak password can be cracked by trying all possible combinations. This helps users realize how vulnerable short or simple passwords are.

⚙️ Behind the Scenes

The project is developed using:

  • HTML/CSS for layout and design
  • JavaScript for real-time checking and visual feedback
  • Node.js + JSON for storing user credentials or password tests

💡 Purpose

The goal is to raise awareness about password safety and help users build better habits that protect their online identity.

Even simple tools like this can play an important role in Cyber Security education by showing how attackers think and why users need to stay ahead.
